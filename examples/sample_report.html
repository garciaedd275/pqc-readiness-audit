Executive Summary

This report assesses network-facing TLS/certificate cryptography against post-quantum risk. It does not test whether an attacker can break these systems today — it tests whether the cryptography in use today will still protect this traffic once a cryptographically relevant quantum computer (CRQC) exists, and whether traffic captured today could be decrypted retroactively ("harvest now, decrypt later").

Demo - RSA 2048 Only (badssl.com) TLS 1.0 RSA Vulnerable (shor) RSA's security rests on integer factorization, which Shor's algorithm solves in polynomial time on a cryptographically relevant quantum computer (CRQC). This holds for any RSA key size — a bigger key raises the classical difficulty but not the quantum one. For key exchange: migrate to ML-KEM (FIPS 203), ideally via a hybrid classical+PQC key exchange during the transition. For signatures: migrate to ML-DSA, Falcon, or SLH-DSA. low internet 15y

Migration Timeline (NIST / CNSA 2.0 Anchors)

This assessment's urgency framing is anchored to public federal guidance, not an arbitrary internal deadline:

  • Aug 2024 — NIST finalizes the first PQC standards: FIPS 203 (ML-KEM / Kyber, key encapsulation), FIPS 204 (ML-DSA / Dilithium, signatures), and FIPS 205 (SLH-DSA / SPHINCS+, signatures).
  • Nov 2024 — NIST IR 8547 (initial public draft) proposes deprecating ~112-bit-security classical algorithms (RSA-2048, ECC P-256/secp256r1) by 2030.
  • Jan 1, 2027 — CNSA 2.0: new National Security System equipment acquisitions are expected to be CNSA 2.0-compliant by default.
  • 2030 — NIST target deprecation date for RSA-2048/ECC P-256-class algorithms. CNSA 2.0 target for exclusive use on software/firmware signing and networking equipment.
  • 2033 — CNSA 2.0 target for exclusive use on web, cloud, and operating systems.
  • 2035 — NIST target date after which RSA/ECC (at any key size) are disallowed. OMB M-26-15 sets this as the full-migration deadline for remaining federal systems, consistent with National Security Memorandum 10.

Sources: NIST IR 8547 (Transition to Post-Quantum Cryptography Standards), NSA CNSA 2.0 Transition Timeline (CSA, 2022, reaffirmed 2025), OMB M-26-15, National Security Memorandum 10.

Scope: network-facing TLS/X.509 only (data-at-rest, VPN/IPsec, SSH, and HSM-embedded keys are out of scope for v1). Classification logic is rule-based and fully editable — see pqc_audit/rules.yaml.
